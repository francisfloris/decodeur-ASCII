Guide de démarrage rapide

1 Créer un compte

Inscrivez-vous gratuitement sur la plateforme pour accéder à toutes les fonctionnalités.

2 Télécharger vos fichiers

Cliquez sur "Lancer décodage" pour traiter automatiquement vos fichiers.

4 Analyser les résultats

Consultez vos données décodées dans le dashboard avec filtres et exports.

FAQ

Comment fonctionne le décodage MSC ?
Le système analyse chaque ligne de vos fichiers et extrait automatiquement les informations : type d'événement, date/heure, numéros appelant/appelé, durée, cellules et MSC.
Quels sont les types d'événements supportés ?
CALL (appels vocaux), SMS (messages texte), DATA (transferts de données).
Combien de temps dure le traitement ?
Le temps de traitement dépend de la taille du fichier. En moyenne, 1000 lignes sont traitées en 30 secondes.
Puis-je exporter mes données ?
Oui, vous pouvez exporter vos données en CSV ou TXT depuis le dashboard ou via l'API.
Mes données sont-elles sécurisées ?
Absolument. Toutes les données sont chiffrées, les accès sont contrôlés et nous respectons le RGPD.

Fonctionnalités avancées

Filtrage et recherche

Utilisez les filtres du dashboard pour rechercher par :

  • Période (date de début/fin)
  • Numéro appelant ou appelé
  • Type d'événement (CALL, SMS, DATA)
  • MSC ou cellule
  • Durée d'appel

API REST

Intégrez le Décodeur MSC dans vos applications via notre API REST complète :

# Exemple d'authentification curl -X POST https://api.decodeur-msc.com/v1/auth/login \ -H "Content-Type: application/json" \ -d '{"email": "user@example.com", "password": "password"}'

Export de données

Exportez vos données dans différents formats :

  • CSV pour Excel/Google Sheets
  • TXT pour traitement texte
  • JSON pour intégration API
