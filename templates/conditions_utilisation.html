2. Description des services

Le Décodeur MSC est une plateforme de traitement et d'analyse de données MSC (Mobile Switching Center) qui permet :

  • Le téléchargement et le traitement de fichiers MSC
  • Le décodage automatique des données de communication
  • L'analyse et la visualisation des données traitées
  • L'export des données dans différents formats
  • L'accès à une API REST pour l'intégration
