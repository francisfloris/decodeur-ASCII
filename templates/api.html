API Documentation

Documentation complète de l'API REST pour intégrer le Décodeur MSC dans vos applications.

Authentification

L'API utilise l'authentification JWT (JSON Web Token). Vous devez d'abord obtenir un token en vous authentifiant.

POST /api/v1/auth/login

Authentification et obtention du token JWT

Corps de la requête :

{ "email": "user@example.com", "password": "password123" }

Réponse :

{ "success": true, "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "user": { "id": 1, "email": "user@example.com", "role": "user" } }

Endpoints de données

GET /api/v1/data

Récupérer les données décodées

Paramètres de requête :

Paramètre Type Description
start_date string Date de début (YYYY-MM-DD)
end_date string Date de fin (YYYY-MM-DD)
appelant string Filtrer par numéro appelant
msc string Filtrer par MSC
GET /api/v1/export

Exporter les données en CSV

Paramètres :

?format=csv&start_date=2024-01-01&end_date=2024-12-31

Gestion des utilisateurs

GET /api/v1/users

Liste des utilisateurs (Admin uniquement)

PUT /api/v1/users/{id}

Modifier un utilisateur (Admin uniquement)

Exemples d'utilisation

Python avec requests

import requests # Authentification response = requests.post('http://localhost:5000/api/v1/auth/login', json={ 'email': 'user@example.com', 'password': 'password123' }) token = response.json()['token'] # Récupérer les données headers = {'Authorization': f'Bearer {token}'} data = requests.get('http://localhost:5000/api/v1/data', headers=headers) print(data.json())

JavaScript avec fetch

// Authentification const response = await fetch('/api/v1/auth/login', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ email: 'user@example.com', password: 'password123' }) }); const { token } = await response.json(); // Récupérer les données const data = await fetch('/api/v1/data', { headers: { 'Authorization': `Bearer ${token}` } });
